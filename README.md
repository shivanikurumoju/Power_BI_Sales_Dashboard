# Power BI Sales Dashboard

## Project Overview

This project analyzes sales data using Microsoft Power BI to identify revenue trends, product performance, customer insights, and business KPIs. The dashboard was built using Power Query for data transformation and DAX for calculated measures.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## Key Features

- KPI Cards
- Sales Trend Analysis
- Product Performance
- Category-wise Sales
- Interactive Filters and Slicers
